Kebijakan Privasi

Terakhir diperbarui: 19 November 2026

GajiCVKita (\"kami\") menghargai privasimu. Kebijakan ini menjelaskan data apa yang kami (dan layanan pihak ketiga yang kami gunakan) proses saat kamu memakai gaji.cvkita.id. Kami mengikuti prinsip UU Perlindungan Data Pribadi (UU PDP) Nomor 27 Tahun 2022.

1. Data yang TIDAK kami kumpulkan atau simpan permanen

  • Perhitungan gaji (Kalkulator, Adu Offering): Semua angka yang kamu masukkan (gaji pokok, tunjangan, PTKP, dll.) diproses sepenuhnya di browser kamu (client-side JavaScript). Data ini tidak pernah dikirim ke server kami, tidak disimpan, dan tidak bisa diakses oleh kami.
  • Cookie pelacakan milik sendiri: Kami tidak memasang cookie tracking sendiri.
  • Kami tidak menjual atau membagikan data pribadi apa pun.

2. Data yang diproses secara terbatas (legal basis: Legitimate Interest & Consent)

  • Fitur AI Offer Analyzer (upload PDF / paste teks): Saat kamu memakai fitur ini, dokumen atau teks yang kamu kirim diproses sementara di server kami untuk:
    • Ekstraksi teks dari PDF (maks 3 MB, validasi magic-byte %PDF)
    • Analisis AI via OpenRouter (model qwen3.7-flash, reasoning:{enabled:false})
    Data ini TIDAK disimpan permanen di database kami (tidak ada KV write pada endpoint gratis /api/import-offer dan /api/ai/preview-offer) dan TIDAK dipakai untuk melatih model. Hasil analisis dikembalikan ke browser kamu dan bersifat session-only.
  • Statistik kunjungan anonim (HG tracking): Kami mencatat event anonim (page view, simulasi, perbandingan, analisis, pembayaran) secara agregat di Cloudflare Workers KV (namespace hg:stat:daily:*) tanpa nama, tanpa IP, tanpa profil pengguna — hanya counter harian untuk keperluan pengembangan produk dan metrik konversi.
  • Pembayaran lisensi Pro: Jika kamu membeli upgrade Pro (Rp 29.000), pembayaran diproses oleh Midtrans (GoPay, Virtual Account, dll.). Kami hanya menerima konfirmasi status pembayaran dan menerbitkan kode lisensi HG-XXXX-XXXX — bukan detail kartu/rekeningmu. Data lisensi disimpan di KV namespace hg:lic:* dengan idempotency key.
  • Formulir masukan & dukungan: Pesan yang kamu kirim lewat formulir kontak atau channel CS disimpan untuk ditindaklanjuti.

3. Pihak ketiga yang terlibat

  • Cloudflare Workers & KV: Hosting serverless & penyimpanan counter anonim / lisensi. Lihat Kebijakan Privasi Cloudflare.
  • OpenRouter (AI): Penyedia akses model AI (qwen3.7-flash). Data prompt tidak disimpan OpenRouter untuk training. Lihat Kebijakan Privasi OpenRouter.
  • Midtrans: Payment gateway. Lihat Kebijakan Privasi Midtrans.
  • GitHub Pages: Hosting static assets. Lihat GitHub Privacy Statement.

4. Hakmu (UU PDP)

Sebagai Subjek Data Pribadi, kamu berhak:

  • Mengakses data pribadi yang kami proses tentangmu.
  • Mengoreksi data yang tidak akurat.
  • Meminta penghapusan data (Right to be Forgotten) — untuk data lisensi & pembayaran, hubungi kode@cvkita.id.
  • Membatasi pemrosesan & keberatan pemrosesan.
  • Portabilitas data.

5. Retensi Data

  • Data tracking anonim (hg:stat): dihapus otomatis setelah 90 hari (KV TTL / manual cleanup).
  • Data lisensi (hg:lic): disimpan selama lisensi aktif + 2 tahun untuk keperluan audit & dukungan.
  • Log pembayaran Midtrans: mengikuti kebijakan retensi Midtrans.

6. Keamanan

Kami menerapkan HTTPS (TLS 1.3 via Cloudflare), validasi input ketat (magic-byte PDF, sanitasi teks), CSP header, dan batas rate-limit pada endpoint AI. Endpoint gratis dilarang menulis KV (proteksi kuota 1.000 write/hari).

7. Perubahan Kebijakan

Setiap perubahan materiil akan diberitahu via banner di halaman utama atau email (jika kamu punya lisensi aktif). Terakhir diperbarui: 19 November 2026.
